## Release scope

### Minimal / missed-decision follow-up

The user's screenshot exposed a grid-layout confirmation banner that split text
fragments into separate rows, and an expired review buried under metadata/history.
The follow-up replaces that banner with one compact status/action row. Missed
decisions now lead with explicit review choices (follow up personally, no longer
needed, or a custom note), using the existing review-expiry endpoint. These notes
do not send new instructions, revive old options, or create approval/receipt rows.
Original options and any expired reply remain readable in collapsed history.

Removed redundant list previews, host/timestamp chrome and reply helper paragraphs;
increased essential reading text to 14–16px. Source recommendations, exact option
answers/consequences, missing evidence and uncertainty remain available before
commitment. Browser review of a synthetic expired item advanced to the next inbox
item and retained its expired outcome. Regression checks ensure no answer row is
created. Final checks: **805 Bun tests**, **109 portable tests**, **17/17 smoke**,
typecheck, frozen install, foundation and diff checks passed.

Screenshots `20-clean-expired-desktop.png`, `21-clean-expired-mobile-light.png`,
`22-clean-expired-mobile-dark.png` and `23-local-minimal-ready.png` record the final
state. At 390px the review choices and primary action fit without horizontal
overflow. The existing 7194 workspace was refreshed only after checking for an
empty draft; no user decision was submitted or reset during QA.

Do not call this broadly production-ready from local QA alone. Tailnet clients,

deployment change is implied by this polish pass.
